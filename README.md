# ExamPrep

Premium installable PWA for student exam preparation: quizzes, PYQs, handwritten notes, Supabase Auth, private Storage downloads, admin UI, and Vercel-ready deployment.

## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```

See [SETUP.md](./SETUP.md) for Supabase SQL, storage, admin promotion, and Vercel deployment.
